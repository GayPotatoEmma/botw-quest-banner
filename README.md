# Quest Banners
> Adds several bits of UI inspired by recent Zelda games.

## Current available styles
- Breath of the Wild
- Tears of the Kingdom

## Current available features
- Quest Banners
  - Works for accepting and completing quests
- Duty Banners
  - Supports various duty types
    - Dungeons
    - Guildhests
    - Trials
    - Raids
    - PvP
    - Treasure Hunt
    - Deep Dungeons
    - The Masked Carnivale
    - Ultimate Raids
    - Variant and Criterion Dungeons
    - Ocean Fishing
    - Chaotic Alliance Raids

## How to Install
- Go into your Dalamud settings
- Go to Experimental
- Add the following repo:
  - `https://raw.githubusercontent.com/GayPotatoEmma/botw-quest-banner/refs/heads/master/repo.json`
- Refresh the installer
