# Quest Banners
> Adds several styles of Quest Banners to replace the Vanilla Styles, inspired by various other games.

## Current available styles
- Breath of the Wild
- Tears of the Kingdom

## Preview
https://github.com/user-attachments/assets/f939e78b-a10f-405b-96d3-cec7539f98e5

## How to Install
- Go into your Dalamud settings
- Go to Experimental
- Add the following repo:
  - `https://raw.githubusercontent.com/GayPotatoEmma/botw-quest-banner/refs/heads/master/repo.json`
- Refresh the installer
